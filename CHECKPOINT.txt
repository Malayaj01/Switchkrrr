Switchkrr Checkpoint
====================

Where we are right now
----------------------
- Product direction is finalized: Switchkrr is a mentor-led job switching platform.
- Tech stack approved and rebuilt from scratch:
  - Next.js
  - TypeScript
  - Prisma
  - PostgreSQL
  - Signed HTTP-only session auth
- Old Vite/Node prototype was removed.
- New clean codebase is in place.
- Prisma schema exists for:
  - users
  - mentor profiles
  - candidate profiles
  - mentor requests
  - hustles
  - leads
  - progress updates
  - sessions
- Signup/login backend foundation exists.
- Candidate and mentor signup forms exist.
- Basic role-aware dashboard shell exists.
- Landing page has been redesigned with:
  - Switchkrr logo on top-left
  - content sections
  - full-page animated waves
  - final Hinglish line: "Chal aaja, switch krte hai"
- Typecheck and production build are passing.
- App is currently previewable at:
  http://127.0.0.1:3001

What we were doing
------------------
- We were improving the home/landing page design.
- We added more content:
  - About us
  - Why this
  - How we help
  - The concept
- We discussed adding scroll-reveal animation:
  - waves unfolding as user scrolls
  - landing sections animating into view

  - candidate profile completion
  - mentor matching
  - mentor request approval/decline
  - automatic Hustle creation
  - Hustle workspace
  - lead posting and tracking
  - admin dashboard
